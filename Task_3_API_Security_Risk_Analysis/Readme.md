# Task 3 - API Security Risk Analysis

## Objective

Perform an API security assessment to identify common risks related to authentication, authorization, data exposure, and API abuse.

## Tools Used

* Postman
* Browser Developer Tools
* Public API Test Environment

## Skills Demonstrated

* API Security Analysis
* Authentication Review
* Authorization Assessment
* Risk Identification
* Security Documentation

## Key Risks Identified

* Excessive Data Exposure
* Broken Authentication
* Broken Authorization
* Lack of Rate Limiting
* Insufficient Input Validation

## Deliverables

* API Security Risk Analysis Report
* Endpoint Documentation
* Risk Assessment
* Remediation Plan
* Supporting Screenshots

## Learning Outcomes

This project demonstrates understanding of common API security weaknesses and recommended mitigation strategies based on industry best practices and OWASP API Security principles.
