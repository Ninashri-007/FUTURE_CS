# FUTURE_CS_01 - Cyber Security Internship Tasks

## Overview

This repository contains the cybersecurity internship tasks completed as part of the Future Interns Cyber Security Program. The projects demonstrate practical skills in vulnerability assessment, secure coding, and network intrusion detection.

## Task 1 - Vulnerability Assessment

### Objective

Perform a vulnerability assessment of a web application using industry-standard security tools.

### Tools Used

* Nmap
* OWASP ZAP
* Browser Developer Tools

### Deliverables

* Vulnerability Assessment Report
* Security Findings
* Screenshots and Evidence

---

## Task 2 - Secure Coding Review

### Objective

Analyze insecure code, identify vulnerabilities, and implement secure coding practices.

### Skills Demonstrated

* Vulnerability Identification
* Secure Code Refactoring
* Security Documentation
* Security Best Practices

### Deliverables

* Vulnerable Code
* Remediated Code
* Secure Coding Report

---

## Task 3 - Network Intrusion Detection System (NIDS)

### Objective

Deploy and configure a Network Intrusion Detection System to monitor network traffic and detect suspicious activities.

### Tools Used

* Suricata
* Wireshark
* Kali Linux

### Deliverables

* Configuration Files
* Alert Logs
* Screenshots
* Documentation
